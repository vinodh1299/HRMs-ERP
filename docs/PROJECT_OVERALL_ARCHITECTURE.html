2. Core Layer Specifications

🛠️ Layer 1: Core UI & Voice Engine

  • Frontend Stack: Flutter 3.x Web & Mobile built with Dart.
  • State Management: Riverpod providers combined with custom ValueNotifier event bus.
  • Voice System: HTML5 Web Speech API for Mic Speech-To-Text paired with Web SpeechSynthesis API for Voice-Over TTS audio output.

🏢 Layer 2: ERP Application Modules

  • Home Dashboard: Web clock-in/out, staff presence modal, announcements, polls.
  • Me Section: Monthly attendance, work modes, leave balances, regularizations.
  • Helpdesk: Service tickets across IT, HR, Maintenance, Finance, CPD, Inventory, HOB, Media.
  • Teams Chat: Channels (#general, #maintenance-updates) and DMs.

🌐 Layer 3: API Gateways & Synchronization

  • Central ChatSync: ChatService event bus routes messages from floating chatbots and AI drawers to target team chats live.
  • Express Backend API: Service at http://localhost:4001/api/ai exposing /chat, /agent, /confirm, /decline.

🤖 Layer 4: HRMs-AI Engine & HITL Safety

  • RAG Policy Chatbot: Hybrid BM25 FullText + Cosine Similarity vector search over 3072-dim embeddings.
  • Action Agent: ReAct function tool calling (createTicket, assignTicket, applyLeave, sendMessageToUserOrChannel, queryTeamAttendance).
  • HITL Risk Evaluation: Staged in agent_pending_actions table with interactive UI confirmation cards.
